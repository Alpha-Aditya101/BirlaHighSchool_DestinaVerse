# Suryapur — Digital Museum & Smart City Portal

Welcome to the Suryapur Digital Museum & Smart City Portal repository.

## 📝 Markdown Content Sync (Live Editing)

Each page on the website is linked to a corresponding `.md` (Markdown) file in the root directory:

| Web Page | Markdown Source File |
|---|---|
| `index.html` | `index.md` |
| `about.html` | `about.md` |
| `heritage.html` | `heritage.md` |
| `visit.html` | `visit.md` |
| `community.html` | `community.md` |
| `gallery.html` | `gallery.md` |
| `itinerary.html` | `itinerary.md` |

### How to Edit Web Page Content:
1. Open any of the `.md` files (e.g. `index.md`, `about.md`, `heritage.md`, etc.).
2. Edit any field value inside the Markdown file (for example, change `hero_title` or `welcome_description`).
3. Save the file and refresh your browser page.
4. The page will automatically fetch and render your new content live!

You can also use formatting such as `*italic*`, `**bold**`, or `*br*` for line breaks inside text fields.

## 🧭 Navigation & Redirects
